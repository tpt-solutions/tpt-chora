# tpt-chora-compat

Migration and adoption tooling for [tpt-chora](https://github.com/tpt-solutions/tpt-chora): an HTML/CSS-to-Chora-IR transpiler, a Wasm/FFI interop bridge, an embeddable `<tpt-chora>` web component, and CDN deployment bootstrap, built on [`tpt-chora-render`](https://crates.io/crates/tpt-chora-render).

## Status

Part of tpt-chora's Phase 1 rendering engine. API is pre-1.0 and may change.

See the workspace [ARCHITECTURE.md](https://github.com/tpt-solutions/tpt-chora/blob/master/ARCHITECTURE.md) for how this crate fits into the rest of tpt-chora.
