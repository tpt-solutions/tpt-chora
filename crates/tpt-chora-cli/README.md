# tpt-chora-cli

Adoption tooling CLI for [tpt-chora](https://github.com/tpt-solutions/tpt-chora): the `tpt-chora` binary, providing `doctor` diagnostics, project scaffolding, and CSS compatibility reports.

## Status

Part of tpt-chora's Phase 1 rendering engine. API is pre-1.0 and may change.

## Installation

```sh
cargo install tpt-chora-cli
```

See the workspace [ARCHITECTURE.md](https://github.com/tpt-solutions/tpt-chora/blob/master/ARCHITECTURE.md) for how this crate fits into the rest of tpt-chora.
