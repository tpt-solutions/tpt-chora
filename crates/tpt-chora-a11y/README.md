# tpt-chora-a11y

Accessibility and semantics engine for [tpt-chora](https://github.com/tpt-solutions/tpt-chora) ("The Bridge"): a semantic IR tree, an OS accessibility bridge, and focus traversal.

## Status

Part of tpt-chora's Phase 1 rendering engine. API is pre-1.0 and may change. Used by [`tpt-chora-runtime`](https://crates.io/crates/tpt-chora-runtime).

See the workspace [ARCHITECTURE.md](https://github.com/tpt-solutions/tpt-chora/blob/master/ARCHITECTURE.md) for how this crate fits into the rest of tpt-chora.
