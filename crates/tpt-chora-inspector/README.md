# tpt-chora-inspector

Developer experience tooling for [tpt-chora](https://github.com/tpt-solutions/tpt-chora): the Chora Inspector overlay, GPU timing, dirty-rect/overdraw heatmaps, hot reload, and color-blindness proofing, built on [`tpt-chora-render`](https://crates.io/crates/tpt-chora-render).

## Status

Part of tpt-chora's Phase 1 rendering engine. API is pre-1.0 and may change.

See the workspace [ARCHITECTURE.md](https://github.com/tpt-solutions/tpt-chora/blob/master/ARCHITECTURE.md) for how this crate fits into the rest of tpt-chora.
